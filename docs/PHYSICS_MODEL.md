# 光线模型

阶段 3 使用静止观察者的局部视线，反向积分非旋转史瓦西时空的零测地线。黑洞位于原点。场景长度以默认史瓦西半径为单位，「主体尺度」调整实际史瓦西半径与该单位的比例。

设 u = Rₛ/r，φ 为光线在轨道平面内扫过的角度。积分方程为 d²u/dφ² = 1.5u² − u。初值取 u₀ = Rₛ/r₀，u′₀ = −u₀√(1−u₀)·cos(ψ)/sin(ψ)，其中 ψ 是局部视线与外向径向的夹角。每个像素用四阶 Runge–Kutta 积分，低、中、高档分别最多执行 64、96、144 步。依据 [俄勒冈州立大学的史瓦西光线推导](https://sites.science.oregonstate.edu/coursewikis/GGR/book/content/bending.html)。

- **事件视界**位于 r = Rₛ。积分到达该边界时停止追踪背景。
- **黑洞阴影**是观察图像中背景光无法到达的区域。关闭透镜时改用半径约 2.598 Rₛ 的球形遮挡代理，便于和直线路径对比。
- **光子球**是 r = 1.5 Rₛ 处的不稳定圆形光轨道所在球面。
- **光子环**是光线在光子球附近绕行后形成的细窄像。当前可见亮弧由弯曲光路穿过发光盘产生，有限采样只能表现其宽尺度结构，无法分辨高阶子环。

每一小段光路与倾斜薄盘求交，在盘面局部坐标中取样温度色调、噪声和透明度，按从近到远的顺序混合。离开 r = 80 的光路使用外推方向取样同一份程序化星空立方贴图。盘面接近观察者的一侧按局部轨道速度投影提亮，色彩、增亮幅度和吸积盘透明度属于艺术近似。

光路交点采用线段插值。接近临界轨道时，有限步数会截断长路径，影响环的细节；近径向视线使用直线极限近似。当前省略盘面厚度、频移和旅行时间，使用远场星空，模型限于非旋转黑洞。

## 深空飞行

探索模式在距黑洞中心 45 个场景长度单位之外先沿直线传播。与近场球相交的光线从入射点继续史瓦西积分，未相交的光线直接采样天空。该分段近似略去远区弱偏折。近处的星云层使用方向噪声与有限视差，远星立方贴图仅随观察方向改变。飞行速度、推进、航点安全距离和视界外淡出是场景规则，未用于验证真实航天轨道。
