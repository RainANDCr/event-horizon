# 开发进度

- 阶段 0：工程配置、实时深空画布、基础 HUD、WebGL2 降级和测试入口已实现。实测结果见 [测试报告](TEST_REPORT.md)。
- 阶段 1：完成实时阴影遮挡、种子星野、星尘、远景星云和四项观测参数。
- 阶段 2：完成实时吸积盘、近远侧深度遮挡、盘面参数、纹理质量和播放控制。
- 阶段 3：加入史瓦西光线积分、星空偏折、盘面多次交点、方向性亮度和直线光路对比。
- 阶段 4：加入自由镜头、桌面与触控输入、六组电影镜头和视界外淡出。
- 阶段 5：加入响应式 HUD、物理与视觉参数分组、本地参数恢复、场景收藏、PNG 截图和纯净观赏。
- 阶段 6：加入电影色调映射、分档泛光和星尘、镜头光学及可选合成环境音。
- 阶段 7：加入科学导览、场景预设、收藏管理、JSON 往返、带水印 PNG 和 WebM 录制。
- 阶段 8：完成动态分辨率、帧率显示、生产构建与发布文档。实际验证范围见测试报告。
- 阶段 9：加入六自由度飞行、程序化探测器、五个深空区域、航点、五条巡航路线和视界外接近过场。
