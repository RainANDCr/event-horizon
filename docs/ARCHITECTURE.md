# 渲染架构

- `src/main.ts` 连接页面与渲染生命周期。
- `src/core/viewport.ts` 管理 WebGL2、单一渲染循环、画布尺寸、页面可见性和上下文恢复。
- `src/core/frame.ts` 计算帧间隔，限制 DPR 和长帧跳变。
- 播放期间按约一秒窗口统计绘制帧数，连续两窗低于 32 FPS 时降低一档渲染比例，连续四窗高于 54 FPS 时恢复一档。比例从 100% 到 55%，上限 DPR 为 1.5。暂停、标签页切换与录制会清空当前采样，录制期间保留已有动态比例。
- `src/camera/controller.ts` 管理鼠标、触控和键盘输入，用阻尼更新绕原点的相机。电影镜头接收同一个渲染循环的时间步长，结束或手动接管时保留当前视角。
- `src/camera/shots.ts` 定义六组镜头和缓动取样。Horizon Descent 在距中心 4.2 个场景长度单位处淡出，全程保持在可调事件视界之外。
- `src/state/settings.ts` 统一参数范围、默认值和枚举，读取版本 1 设置并兼容未版本化的对象。场景收藏使用独立的本地存储键，恢复默认参数时保留收藏。
- `src/ui/hud.ts` 管理 HUD 工具栏、设置对话框、场景收藏和移动端参数抽屉。
- `src/ui/explore.ts` 将科学主题与场景预设映射到现有设置和相机控制，并记录新手引导是否已跳过。
- `src/export/media.ts` 保存 PNG 与配置文件，检查 WebM 编码支持，并管理画布录制的 MediaRecorder 和媒体轨道。
- `src/flight/controller.ts` 管理六自由度输入、鼠标锁定、惯性飞行、探测器跟随、巡航控制权和 HUD。观测与飞行互斥地更新同一相机，继续使用同一个渲染循环与后处理。
- `src/flight/routes.ts` 定义五条样条路线，生成安全绕行入口，以弧长取样并插值朝向。手动飞行按指数速度响应积分，使用扫掠球体检查安全边界。
- `src/flight/probe.ts` 以原生几何体生成探测器。追踪镜头和探测器以探测器位置为原点绘制，光线着色器加回世界原点偏移。世界坐标以黑洞为中心保存，手动飞行限制在 20,000 个基准长度单位内。
- `src/flight/nebula.ts` 在偏折后的天空采样方向上叠加种子噪声星云与星团。星云使用 0、2 或 4 层远景近似，低光线画质或低渲染比例最多使用 2 层。粒子尾迹单次绘制并限量。
- `src/flight/waypoints.ts` 在独立的本地键保存自定义航点，以同一世界坐标驱动 HUD 指示和导出。
- `src/rendering/bloom.ts` 提供分档泛光和独立的暗角与轻微色散。直接渲染使用场景着色器的色调映射，后处理使用线性中间目标，由 OutputPass 统一完成 ACES 与显示色彩转换。两项效果关闭时跳过合成器。PNG 捕获在画布完成绘制后读取。
- `src/audio/ambience.ts` 在用户主动点击后创建音频上下文。多频振荡器与缓慢调制生成氛围，观察距离影响低通滤波，关闭时释放音频上下文。
- `src/rendering/deep-space.ts` 创建并释放种子星野、星尘、星云和相机，并应用观测参数。
- `src/rendering/lensed-view.ts` 使用相机逆投影生成光线，在单个全屏 GPU pass 中处理黑洞捕获、盘面交点和星空采样。星空立方贴图只在星空参数变化或上下文恢复后重绘。
- `src/rendering/accretion-disk.ts` 在 `shadeDisk` 中按盘面交点计算热色、透明度与多尺度噪声。角速度按半径的 −3/2 次幂变化，纹理画质使用 2、3 或 4 层噪声。
- `src/styles/` 管理观测画布与基础 HUD 的布局。
- `tests/` 包含帧参数单测及 WebGL2、窗口缩放和降级场景的浏览器测试。

默认相机距离为 13 个场景长度单位。积分方法及误差范围见 [光线模型](PHYSICS_MODEL.md)。
