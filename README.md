# Event Horizon · 黑洞实验室

当前为阶段 9。顶部「主模式」可切换 Observation、Exploration、Probe 和 Cinematic。观测模式沿用原有黑洞参数与镜头，探索与探测器模式进入深空飞行。

### 深空飞行

- WASD 平移，Space / Ctrl 升降，Q / E 滚转，Shift 临时加力，滚轮改变速度上限，R 复位。点击「锁定鼠标」后可直接转向，Esc 释放鼠标。也可在画布拖动转向。
- Probe 支持第一人称和第三人称。第三人称下按住 Shift 拖动可环绕探测器，可调整跟随距离和回正镜头。
- 「驾驶与环境」提供五种深空区域与分档星云。「自动巡航」提供五条路线，可暂停、继续、停止或通过方向输入接管。
- 「导航与航点」可选择内置目标，保存、重命名、删除或导出自定义航点。航点在同一浏览器刷新后自动加载。
- Horizon Approach 在事件视界外淡出，随后可继续观察或返回安全点。速度与坐标为场景单位，推进反馈、星云和过场是艺术表现。

### 黑洞实验室

桌面左侧调整参数，右侧查看科学说明，底部控制镜头和播放。手机上可打开底部的参数抽屉。顶部工具支持全屏、PNG 截图和隐藏 HUD，按 Esc 可退出纯净观赏模式。

「科学导览」提供八个主题和六组场景预设。「观察此现象」会切换参数与镜头。「设置」支持重命名、覆盖或删除收藏，以及导入、导出当前参数 JSON。收藏和当前参数分别保存在本机。

「截图」保存当前画布分辨率的 PNG，可在设置中勾选水印。支持画布 WebM 的浏览器可以开始并结束录制，下载的视频包含渲染画面。

「观测参数」中可以独立调节泛光、镜头光学和远景星尘。顶部「环境音」默认关闭，开启后可调音量、静音或关闭。声音由浏览器实时合成，作为艺术配乐使用。

参数自动保存在当前浏览器。「设置」可恢复默认值、减少动态效果，也可为当前参数和观察距离命名并收藏。旋转视觉近似调整盘面速度和亮度偏置，光路仍使用史瓦西模型。

拖动画布或用方向键环绕，滚轮、双指或加减键缩放。「镜头」面板提供六组电影镜头和重置视角。暂停按钮与时间倍率同时控制镜头和盘面动画。拖动或缩放可从电影镜头接回自由观察。

在「观测参数」里切换引力透镜可对比直线与弯曲光路，也可切换三档光线画质。「吸积盘」面板可调整盘面参数。[光线模型](docs/PHYSICS_MODEL.md)

使用 Node.js 24 LTS。

```sh
npm run dev
```
